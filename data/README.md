# Data

CSV filenames correspond to Tables 2–8 and 12–16.

- `DD_mm`, `MeanRG_mm`, `MaxRG_mm`: displacement and residual gaps in mm.
- Load budgets and probing radii: N.
- `sigma_field_mm`: offline gap-field RMS; `sigma_online_mm`: noise standard deviation per acquisition.
- `lambda`: mm/N; `eta` and stiffness scales: dimensionless.
- Win rates: percent. Paired differences: COLA minus baseline.
